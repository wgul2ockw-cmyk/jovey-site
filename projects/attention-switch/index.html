Attention Switch
เวลาไปไหน ใจไปทางไหน

Attention Switch คือแอปจับเวลาความสนใจของ Jovey ที่บันทึกเวลารายโปรเจกต์และจำนวนครั้งที่คุณแตะสลับงาน เพื่อกลับมาดูจังหวะการทำงานจากเซสชันของตัวเอง

เปิด Attention Switchวิธีเริ่มเซสชันแรก

จับเวลาความสนใจต่างจากจับเวลาอย่างไร

การจับเวลารวมตอบได้ว่านั่งทำงานนานเท่าไร แต่ยังไม่บอกว่าเวลาแบ่งไปให้โปรเจกต์ไหน Attention Switch ให้คุณแตะโปรเจกต์ที่กำลังทำ เมื่อความสนใจย้ายไปอีกงานก็แตะโปรเจกต์ใหม่ เพื่อเก็บทั้งเวลาและเส้นทางการเปลี่ยนงาน

แอปบันทึกตามการแตะของคุณ ไม่ได้อ่านใจหรือตรวจจับทุกครั้งที่สมาธิหลุดโดยอัตโนมัติ ถ้าลืมสลับโปรเจกต์ เวลาจะยังอยู่กับงานเดิม ข้อมูลจึงเป็นบันทึกที่ช่วยทบทวน ไม่ใช่การวัดความสนใจทั้งหมดอย่างแม่นยำ

เริ่มเซสชันแรกในห้าขั้นตอน

  1. เพิ่มโปรเจกต์ที่กำลังทำ เช่น อ่านหนังสือ เขียนงาน และงานประสาน เลือกชื่อที่แยกงานได้ชัด แอปรองรับโปรเจกต์ที่ใช้งานพร้อมกันได้ถึงเก้ารายการ
  2. กด Start session แล้วแตะโปรเจกต์ที่กำลังให้ความสนใจ เวลาเริ่มถูกจัดให้โปรเจกต์นั้น
  3. แตะโปรเจกต์ใหม่เมื่อเปลี่ยนงาน การแตะสลับโปรเจกต์เป็นจังหวะที่แอปบันทึก attention switch
  4. ใช้ Task หรือ Note ระหว่างทำงาน เก็บงานย่อยหรือไอเดียโดยไม่เปลี่ยนโปรเจกต์ที่จับเวลาอยู่ การจดอย่างเดียวไม่เพิ่มจำนวนครั้งที่สลับงาน
  5. จบเซสชันแล้วอ่านสรุป ทบทวนเวลาในแต่ละโปรเจกต์ การสลับงาน และคำถามสะท้อนความรู้สึกที่เลือกตอบได้

เซสชันที่มีเวลาจดจ่อรวมไม่ถึง 10 วินาทีจะไม่ถูกเก็บในประวัติ เริ่มจากช่วงทำงานที่มีขอบเขตชัดเจนก่อนหนึ่งช่วง ตั้งเป้าว่าจะบันทึกให้ตรงกับสิ่งที่ทำ มากกว่าพยายามทำให้ตัวเลขออกมาสวย

อ่านจำนวนครั้งที่สลับงานอย่างไร

จำนวนครั้งสูงไม่ได้แปลว่าทำงานไม่ดี งานประสานหลายฝ่ายอาจต้องสลับบ่อยกว่างานเขียนยาวๆ ควรเปรียบเทียบเซสชันที่มีงานและระยะเวลาใกล้กัน แล้วดูว่าการเปลี่ยนงานเกิดจากแผน งานด่วน หรือสิ่งรบกวน

ตัวอย่าง: เซสชันอ่านหนังสือกับเซสชันตอบข้อความงานมีเป้าหมายต่างกัน แม้ใช้เวลาเท่ากัน จำนวนครั้งที่สลับงานก็ไม่จำเป็นต้องเท่ากัน ลองถามว่า “การสลับครั้งนี้ช่วยให้งานเดินหน้าหรือทำให้ต้องเริ่มคิดใหม่?” ก่อนเลือกเปลี่ยนนิสัย

หน้า Trends ช่วยดูประวัติและเส้นทางความสนใจ ส่วน Notes wall รวมไอเดียที่บันทึกไว้ คุณจึงกลับไปหาเหตุการณ์ประกอบตัวเลขได้ ผลเหล่านี้ไม่ได้ใช้วินิจฉัยสมาธิสั้นหรือปัญหาสุขภาพจิต

ข้อมูลอยู่ที่ไหน และควรรู้อะไรก่อนเริ่ม

ข้อมูลโปรเจกต์ เซสชัน และโน้ตบันทึกในเบราว์เซอร์บนอุปกรณ์ที่ใช้ ไม่มีระบบบัญชีหรือการซิงก์ข้อมูลแอปข้ามอุปกรณ์ การเปิดคนละเบราว์เซอร์จึงอาจเห็นคนละชุดข้อมูล และการล้างข้อมูลเว็บไซต์หรือใช้โหมดส่วนตัวอาจทำให้บันทึกไม่อยู่ต่อ

หน้าเว็บมีระบบเก็บไฟล์สำหรับใช้งานออฟไลน์หลังโหลดสำเร็จ แต่การพร้อมใช้งานขึ้นอยู่กับเบราว์เซอร์และพื้นที่จัดเก็บของอุปกรณ์ ข้อมูลการเยี่ยมชมเว็บไซต์ผ่าน Cloudflare Web Analytics แยกจากข้อมูลโปรเจกต์และเซสชันในแอป

Attention Switch ในเส้นทางของ Jovey

เครื่องมือนี้อยู่ในเส้นทาง Personal Growth ของ Jovey โดยเริ่มจากสิ่งที่ทำได้ระหว่างวัน: เลือกงาน รู้จังหวะที่เปลี่ยน และกลับมาทบทวน หากอยากสำรวจแรงจูงใจ ลองอ่าน ENNEAGAME กับการสำรวจตัวเอง หากคำถามเป็นเรื่องการใช้เงิน ลอง MindSpend

คำถามที่พบบ่อยเกี่ยวกับ Attention Switch

ต้องจับเวลาเป็นรอบแบบ Pomodoro ไหม

การใช้งานหลักเริ่มและจบตามเซสชันที่คุณเลือก แล้วบันทึกเวลาตามโปรเจกต์ ไม่ได้กำหนดว่าทุกคนต้องใช้ช่วงทำงานเท่ากัน คุณวางแผนพักแยกตามงานและความเหมาะสมได้

จดโน้ตแล้วนับเป็นการสลับงานไหม

ไม่ การเพิ่ม Task หรือ Note ระหว่างเซสชันไม่ได้เปลี่ยนโปรเจกต์ที่กำลังจับเวลาและไม่ได้สร้าง attention switch

เปลี่ยนอุปกรณ์แล้วข้อมูลตามไปด้วยไหม
