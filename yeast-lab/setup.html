Jovey · Yeast Lab

พาข้อมูลจากบอร์ดขึ้น Jovey

ESP32 → ส่ง HTTPS ทุก 10 วินาที → Supabase เก็บข้อมูล → Jovey แสดงกราฟและ baseline

เซิร์ฟเวอร์และอุปกรณ์ลงทะเบียนพร้อมแล้ว

ไม่ต้องสร้างโปรเจกต์ ไม่ต้องรัน SQL และไม่ต้องกรอก API key บนเว็บ เปิดกราฟได้โดยไม่ต้องมีบัญชี เหลืออัปโหลดไฟล์และตั้ง Wi-Fi บน ESP32

1 · เปิดกราฟ

เปิด Yeast Lab ได้เลย ไม่ต้องกรอกอีเมลหรือรหัสผ่าน ผู้ที่มีลิงก์สามารถอ่านข้อมูลบอร์ดนี้ได้ การส่งค่าจากบอร์ดยังคงต้องใช้ token อุปกรณ์

2 · เตรียมบอร์ด

  1. ใช้ชุด Yeast_Jovey_Ready_Private.zip ที่ส่งให้ส่วนตัวในแชต ซึ่งใส่เซิร์ฟเวอร์และ token อุปกรณ์ไว้แล้ว ห้ามอัปโหลดชุดนี้ไปเว็บสาธารณะ
  2. ทำตาม START_HERE_TH.txt เพื่อใส่ Wi-Fi และเตรียมใบรับรอง HTTPS บน Mac เครือข่ายต้องออกอินเทอร์เน็ตได้ โค้ดยังล็อกอิน Wi-Fi แบบหน้าเว็บให้อัตโนมัติไม่ได้
  3. เปิด Yeast_Cloud.ino ใช้ ESP32 Dev Module พร้อม OneWire / DallasTemperature แล้วกด Upload เปิด Serial Monitor 115200

สายเดิม: DS18B20 G4, MQ3 G34, MQ135 G35 โดยแต่ละ MQ ผ่านตัวแบ่งแรงดัน 10K/10K

ไฟเลี้ยงและสาย USB

ตอนอัปโหลด ใช้สาย Micro USB ที่ส่งข้อมูลได้จาก ESP32 ไปคอมหรือ USB hub หลังตั้งค่าและอัปโหลดสำเร็จ เปลี่ยนปลาย USB ไปหัวชาร์จ 5V ได้ ไม่ต้องต่อสายจากบอร์ดเข้าเซิร์ฟเวอร์ เพราะข้อมูลส่งผ่าน Wi-Fi แนะนำหัวชาร์จคุณภาพดี 5V 2A; ยังต้องทดสอบว่าสายและทางจ่ายไฟของบอร์ดรองรับเซนเซอร์ที่ต่ออยู่ได้โดยไม่รีเซ็ต Wi-Fi ที่ต้องกดล็อกอินหน้าเว็บยังไม่รองรับอัตโนมัติ

3 · เริ่มรับข้อมูล

รอ Serial แสดง # CLOUD_ACK points=... แล้วเปิด Yeast Lab ดูสถานะ LIVE บอร์ดจะส่งทุกประมาณ 10 วินาที แม้ปิดหน้าเว็บ ข้อมูลที่ส่งถึงเซิร์ฟเวอร์แล้วจะยังอยู่

4 · เก็บ baseline

  1. Serial ต้องแสดง # CLOUD_ACK points=... และตาราง yeast_samples มีแถวเพิ่ม หากมีแค่ IP ยังไม่ได้ยืนยันการส่งขึ้นเซิร์ฟเวอร์
  2. กลับ Yeast Lab รอสถานะ LIVE และกราฟอุณหภูมิ / MQ3 / MQ135 ขยับ
  3. หลังอุ่นเซนเซอร์และจัดสภาพอ้างอิงให้คงที่ ตั้งชื่อ baseline ติ๊กยืนยัน แล้วกด “เริ่มเก็บ 5 นาที”
  4. รอครบเวลา ระบบใช้ median จากจุดที่เข้าเกณฑ์เพื่อแสดงส่วนต่างของสัญญาณ เลือก baseline เก่าหรือดาวน์โหลด CSV ได้ ชื่อและช่วง baseline เก็บเฉพาะในเบราว์เซอร์เครื่องที่กด ส่วนจุดข้อมูลยังอยู่บนเซิร์ฟเวอร์
  5. ทดลองปิดเว็บหนึ่งนาทีแล้วเปิดใหม่ ข้อมูลที่ Supabase รับสำเร็จต้องยังอยู่ บอร์ดยังต้องมีไฟและอินเทอร์เน็ต
อ่านตัวเลขให้ถูก

MQ3 / MQ135 เป็น raw ADC ไม่ใช่ CO₂ หรือความเข้มข้นเอทานอล เกณฑ์ baseline ตรวจความครบของข้อมูล ไม่ได้ยืนยันการอุ่นเซนเซอร์ การสอบเทียบ หรือเวลา harvest เว็บแสดงล่าสุดไม่เกิน 600 จุด ส่วนประวัติทั้งหมดอยู่ใน Supabase

คิวรอส่งบนบอร์ดอยู่ใน RAM และหายเมื่อไฟดับ ยังไม่ใช่เครื่องบันทึกแบบ offline ถาวร

ชุดตัวอย่างสำหรับโปรเจกต์อื่น (ไม่มี token จริง) · คู่มือทั่วไป · สิ่งที่ทดสอบแล้วและข้อจำกัด · กลับ Yeast Lab
