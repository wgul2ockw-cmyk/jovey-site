Implemented prototype (core flow browser verified):

- Four original Blender-generated GLB concept facilities, plus GLB import.
- Self-contained glTF 2.0 validation, 30 MB limit, external asset URLs rejected.
- model-viewer orbit/zoom, palette/roughness material transform, GLB export.
- IndexedDB stores original + styled asset, roadmap, provenance, timestamp and style
  version. Local demo filters Personal/Team. NOT a security boundary or cloud sync.
- Reuse restores the saved style, plan and original source. No automatic public upload.

Production pipeline contract to coordinate with backend/MCP worker:
1. POST project brief in authenticated workspace -> job ID. Server derives owner,
   checks membership; retrieves only authorized sources with citations.
2. Planner returns structured proposed steps, dependencies, unknowns and facility
   requirements. User acceptance creates a new plan revision, not completed progress.
3. Source/generate model job requires provider choice, licence and cost constraints.
   Save immutable source GLB plus source provenance/licence. Original CAD/IFC can be
   retained separately; conversion needs an authorized worker. None currently wired.
4. Style worker produces derived low-poly mesh, material palette, source hash,
   style version and preview. Material recolouring alone is NOT full retopology.
5. Save versioned asset under owner/team access policies. Signed asset retrieval;
   no private assets in GitHub Pages/public dashboard JSON. MCP must enforce identical
   server-side policies. User explicitly shares or copies Personal assets into Team.
6. Browser polls job states queued/running/review/failed/ready; retry uses idempotency
   keys. Never silently substitute a template and call it AI output.
