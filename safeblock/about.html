About SafeBlock

A local ad and tracker blocker for desktop Chrome.

SafeBlock v1.7.0

Previously named QuietBlock.

Local processing

Bundled filters run inside Chrome. SafeBlock has no telemetry, account, external DNS service, or hosted filtering. No browsing history is collected.

Separate protection settings

Pause network blocking, allow a website, or change each optional protection separately. Additional access is requested only when you enable a feature.

Stored information

SafeBlock saves website exceptions, feature switches, and your appearance preference locally. Chrome displays a per-page blocked-request count on the toolbar icon. Earlier developer-build totals, if present, are kept as historical data and no longer increase.

Bundled rules include 3,560 domains from Peter Lowe’s ad and tracking server list, retrieved November 8, 2026. Filter updates are bundled in extension releases.

Filter source & attribution
What SafeBlock does not promise

No blocker can guarantee every ad, tracker, or privacy risk is removed. First-party and unknown tracking can remain. YouTube filtering is experimental. SafeBlock does not promise anonymity or protection from every cyberattack.

This is a desktop Chrome extension. It does not run in Chrome on iPhone or iPad, and does not block traffic in native apps. It is not a signed iOS app.

Chrome’s Safe Browsing, passwords, DNS, proxy, and account settings are not modified.
