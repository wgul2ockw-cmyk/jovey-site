SafeBlock support

Desktop Chrome · Local ad and tracker filtering

Contact

Email Mdthitipong@hotmail.com with the SafeBlock version, Chrome version, and a description of the issue. Include a public website address only if you are comfortable sharing it. Avoid sending passwords, private pages, or sensitive screenshots.

Using the compact panel

Pin SafeBlock in Chrome’s toolbar, open it on a website, and use Check status to refresh the summary. Allow on this site adds a network exception for the current domain and its subdomains; Block on this site removes that exact exception. If a parent domain already allows the site, manage that exception in Dashboard → Allowed websites. Reload the site after changing an exception.

Pause all blocking affects network filtering only. Chrome privacy settings, cookie rejection, and YouTube are separate controls. Chrome-owned pages and the Web Store cannot use the site shortcut.

Understanding the counter

Chrome counts blocked requests per page. The icon and popup may show different availability depending on Chrome’s temporary access rules; See icon means Chrome did not expose a readable count to the popup. Navigation resets the count. A request is not the same as a unique ad. Session/lifetime collection from the developer build is not available in the Store build; older totals are retained as historical data.

Ads or cookie dialogs remain

Only known bundled ad/tracker requests are filtered. First-party, unknown, stream-integrated, or sponsored content may remain. Cookie rejection requires optional website access and recognized explicit reject/necessary-only controls. It does not accept all cookies or hide unfamiliar dialogs.

YouTube filtering is experimental. Reload YouTube after changing it. Ads, anti-adblock notices, and player changes can still occur. If playback breaks, turn off the YouTube module and reload.

Checking configuration

Open Dashboard → Diagnostics. Its read-only checks confirm filter availability, pause/exception state, local settings, and the toolbar counter. They do not demonstrate full real-world ad coverage.

Installation and compatibility

Use the download and installation page. Chrome Web Store submission is being prepared; no approved Store listing is claimed. Chrome on iPhone and iPad cannot install desktop Chrome extensions. No signed iOS app is provided.

A future Store installation has a different identity from an unpacked developer installation, so settings and historical totals do not transfer automatically. Keep the old installation backed up until you have completed the transition.
