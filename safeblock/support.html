SafeBlock support

Desktop Chrome · Local ad and tracker filtering

Contact

Email Mdthitipong@hotmail.com with the SafeBlock version, Chrome version, and a description of the issue. Include a public website address only if you are comfortable sharing it. Avoid sending passwords, private pages, or sensitive screenshots.

Using the compact panel

Pin SafeBlock in Chrome’s toolbar, open it on a website, and use Check status to refresh the summary. Allow on this site adds a network exception for the current domain and its subdomains; Block on this site removes that exact exception. If a parent domain already allows the site, manage that exception in Dashboard → Allowed websites. Reload the site after changing an exception.

Pause all blocking affects network filtering only. Chrome privacy settings, cookie handling, and YouTube are separate controls. Chrome-owned pages and the Web Store cannot use the site shortcut.

Understanding the counter

Chrome counts blocked requests per page, resetting on navigation. The icon and popup may show different availability under Chrome’s temporary access rules. A request is not a unique ad or a cookie choice.

Version 1.9 adds optional local session/lifetime totals. Enable totals and grant Chrome’s reporting permission, then allow about one minute for refresh. Recorded lifetime totals remain on the same installation. Browser interruptions and reporting limits can leave gaps. If reporting is unavailable after an extension update, reload the extension or restart Chrome, reopen the panel, and check permission status.

Ads or cookie dialogs remain

Only known bundled ad/tracker requests are filtered. First-party, unknown, stream-integrated, or sponsored content may remain.

In version 1.9, select Essential cookies only to try recognized necessary-only/rejection controls and hide remaining detected cookie prompts. It never selects Accept all, but hiding a prompt does not prove optional cookies were rejected. No extension can guarantee handling every website’s dialog. Block all cookies is stricter and may break sign-ins or essential features. Off clears SafeBlock’s cookie rules.

If a site gets stuck, select Show cookie prompts on this site and reload to make a choice manually. Network exceptions and cookie exceptions are separate. Grant requested website permissions for page handling and reload pages after changing modes.

YouTube filtering is experimental. Reload YouTube after changing it. Ads, anti-adblock notices, and player changes can still occur. If playback breaks, turn off the YouTube module and reload.

Checking configuration

Open Dashboard → Diagnostics. Its read-only checks confirm filter availability, pause/exception state, local settings, and the toolbar counter. They do not demonstrate full real-world ad coverage.

Installation and compatibility

Install SafeBlock from the Chrome Web Store. The Store lists the currently approved version; update features described here require version 1.9.0 or later. Google review and Chrome’s update rollout control availability. Chrome on iPhone and iPad cannot install desktop Chrome extensions. No signed iOS app is provided.

A Store installation has a different identity from an unpacked developer installation, so settings and totals do not transfer automatically. Keep the old installation backed up until you have completed the transition.
