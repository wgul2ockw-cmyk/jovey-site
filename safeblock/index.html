A FEW GOOD QUESTIONS

Before you settle in.

How do I get started?

Install SafeBlock from the Chrome Web Store, then pin it from Chrome’s Extensions menu. Open its dashboard to choose optional controls. For manual installation, follow the ZIP installation guide.

Does the website block ads?

No. The dashboard preview uses sample data to show the interface. Install the extension in desktop Chrome to enable protection.

Will it block every ad?

No blocker catches everything. SafeBlock uses bundled network rules, cookie rejection works on supported banners, and YouTube filtering is experimental. You can allow a website if something stops working.

Can I use it on iPhone or iPad?

This extension is for desktop Chrome. Chrome on iPhone and iPad cannot load it.
