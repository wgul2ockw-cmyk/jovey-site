Install SafeBlock

Version 1.7.0 · Desktop Chrome · Source included

The website is a preview with sample activity. Install the extension to enable actual blocking in Chrome.

Download SafeBlock for Chrome
  1. Download and extract the ZIP.
  2. Move the folder containing manifest.json folder to a permanent location.
  3. Open chrome://extensions in Chrome.
  4. Turn on Developer mode, choose Load unpacked, and select the folder.
  5. Pin SafeBlock, open its dashboard, and enable the optional protections you want. Reload open websites after changes.

Chrome will request browser access when you enable optional features. Cookie rejection requires permission to read and change websites. Its processing is local. No telemetry, external DNS, or hosted ad-blocking service is used.

Already using QuietBlock?

Back up its source folder. Replace the contents of that same folder with the contents of folder containing manifest.json, then click Reload on its existing Chrome extension card. Keeping the same folder and installation preserves settings and any historical totals. Version 1.7 uses a per-page count; previous totals no longer increase.

Loading SafeBlock from a different folder creates a separate installation. Removing the old extension can erase its saved data.

Compatibility and testing

This is a desktop Chrome submission candidate. It has not been uploaded to or approved by the Chrome Web Store. You can test it as an unpacked extension. It is not a signed iOS app. Chrome on iPhone and iPad cannot load it. YouTube filtering remains experimental; some ads may still appear.

56 automated checks passed. The installed Chrome dashboard and compact popup were checked. A controlled test completed a local request while three bundled ad/tracker requests failed and Chrome’s SafeBlock counter showed 3. This is a limited test, not proof of comprehensive live ad or YouTube coverage.
