Install SafeBlock

Version 1.6.0 · Desktop Chrome · Source included

The website is a preview with sample activity. Install the extension to enable actual blocking in Chrome.

Download SafeBlock for Chrome
  1. Download and extract the ZIP.
  2. Move the SafeBlock_Chrome folder to a permanent location.
  3. Open chrome://extensions in Chrome.
  4. Turn on Developer mode, choose Load unpacked, and select the folder.
  5. Pin SafeBlock, open its dashboard, and enable the optional protections you want. Reload open websites after changes.

Chrome will request browser access when you enable optional features. Cookie rejection requires permission to read and change websites. Its processing is local. No telemetry, external DNS, or hosted ad-blocking service is used.

Already using QuietBlock?

Back up its source folder. Replace the contents of that same folder with the contents of SafeBlock_Chrome, then click Reload on its existing Chrome extension card. Keeping the same folder and installation preserves lifetime totals and settings. Session totals restart on reload.

Loading SafeBlock from a different folder creates a separate installation. Removing the old extension can erase its saved data.

Compatibility and testing

This is an unpacked desktop Chrome extension, not a Chrome Web Store release or a signed iOS app. Chrome on iPhone and iPad cannot load it. YouTube filtering remains experimental; some ads may still appear.

38 automated controller checks passed. The redesigned interface was tested in a browser preview using sample state. The new UI has not yet been runtime-tested as an installed Chrome extension. No comprehensive live ad-blocking result is claimed.
